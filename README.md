### Interactive Sentiment Analysis Interface

**Introduction:**

### Email Address Validation

**Introduction:**  
This project implements a classifier to validate email addresses using feature extraction and weight vectors. It includes two versions: one that demonstrates a baseline approach with a predefined weight vector, and another where custom features are developed to improve accuracy.

### BabyNames

**Introduction:**  
This project visualizes historical trends in baby name popularity using a Tkinter-based graphical interface. It processes ranking data from multiple decades (1900–2010) and allows users to search for specific names to display their popularity trends over time.

### Image_processing

**Introduction:**  
This project implements an image processing tool that removes unwanted objects from images by combining multiple photos taken from the same angle using a ghosting technique. The resulting composite image appears clean and free of transient elements, showcasing pixel-level manipulation and image processing skills in Python.

https://github.com/user-attachments/assets/f200e0d3-879a-4ae2-b19d-5dd7fd8528ea

### webcrawler

**Introduction:**  
This project is a web crawler that scrapes baby name data from the Social Security Administration website. It collects data for different decades and prints the total numbers of top male and female names, demonstrating effective web scraping and data extraction techniques in Python.
