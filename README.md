### Image Processing

**Introduction:**  
This project implements an image processing tool that removes unwanted objects from images by combining multiple photos taken from the same angle using a ghosting technique. The final composite image is free of transient elements, demonstrating effective pixel-level manipulation and image processing skills in Python.
